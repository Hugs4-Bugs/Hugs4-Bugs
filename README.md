## 🧭 About

I'm the kind of developer who reads the source before trusting the docs. Systems fascinate me — not just making them work, but understanding exactly *why* they work, down to the root.

Currently a final-year Computer Science student in Kenya, splitting my time between shipping production code and pulling apart enterprise infrastructure to see how it's actually wired together.

```bash
root@buildlab:~$ whoami
> James Kanyago (Nyaga) — "Mr. Root"
> Full-stack developer · Data & systems thinker · Builder for underserved communities
```

- 🔭 **Building:** MindMate AI — a hybrid mental wellness app with dual-mode intelligence
- 🌱 **Learning:** DevOps, Machine Learning, and data-driven systems design
- 💬 **Ask me about:** Python, JavaScript, PHP, Java, SQL, C/C++
- 🎯 **Focus:** technology that's actually usable by the people who need it most
- ⚡ **Fun fact:** I write code the way artists paint — layer by layer, until it holds together
